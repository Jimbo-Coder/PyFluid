High confidence, high impact (do first)
- src/framework/config.cpp
  - Many config keys are parsed and validated through repetitive if/else checks. Use a small schema table (key, type, default, validator) plus one validation dispatcher to avoid drift between defaulting and checks.
  - Benefit: fewer branch mistakes, easier review of new options, lower regression risk.
- src/initial_data/initial_data_state.cpp
  - The IC dispatch tree has repeated hydro/MHD and axis-conversion patterns. Introduce per-IC builder helpers and one shared state-materialization path (primitive reset, EOS-dependent energy, optional B-fields).
  - Benefit: smaller, more maintainable IC addition path.
- src/numerics/flux_factory.cpp
  - Factory selection for Riemann/reconstruction combos is mostly table-like; replace long nested conditionals with compile/runtime capability descriptors.
  - Benefit: clearer unsupported-combo diagnostics and easier extension.
- src/numerics/hierarchy_interpolation.cpp
  - Interpolation loops are readable but verbose with repeated level+direction wrappers. Factor common interpolation envelope + per-level hooks.
  - Benefit: shorter code and easier correctness reasoning.
- src/numerics/ct_edge_flux_register.cpp
  - 2D/3D path shares most logic with only directional and area differences. Consolidate via a small directional helper.
  - Benefit: reduces chance of missed axis updates.
- tools/validation_common.py
  - Several validation wrappers re-implement command-option shaping. Centralize command assembly into one tiny builder to keep CLI behavior consistent.
  - Benefit: less duplicated MPI/reporting surface.
